## 架构增量
- `IVirtualDisk.OpenRead(path) -> Stream`：VHD=FileStream；VMDK=DiscUtils OpenFile；容器=`7z e -so` → MemoryStream（**纯内存，不落地**）。
- `PreviewDispatcher`：扩展名分流 Text/Image/Hex，其余未知格式一律内部 Hex；**只有 .pdf/.docx/... 白名单才走外部**。
  - 文本上限 2MB / 5000 行；BOM 识别 UTF-8/UTF-16LE/BE；无 BOM 严格 UTF-8 失败回退 GB18030(54936)；截断处切断多字节字符时不误判成 GBK。
  - 图片 `BitmapImage` + `CacheOption.OnLoad` + `Freeze()`，Stream 不落地。
  - Hex 前 4KB，16 字节/行，偏移 + HEX + ASCII。
- 新增窗口：`TextViewerWindow` / `ImageViewerWindow`（滚轮缩放、双击适应窗口）/ `HexViewerWindow`；全部 DynamicResource 跟随亮暗主题，Esc 关闭。
- `Common/TempFileRegistry.cs`：外部打开兜底临时文件登记，`App.OnExit` 统一清理。**坑：不要把 VHD 的真实路径登记进去**，否则退出会删用户文件。
- `ArchiveToVhdxService`：7z x 解压 → `DiscUtils.Vhdx.Disk.InitializeDynamic` → `BiosPartitionTable.CreateAligned(WindowsNtfs,...)` → `VolumeManager` + `NtfsFileSystem.Format(volume,"BASALT")` → 逐文件写入。依赖新增 `LTRData.DiscUtils.Vhdx 1.0.47`。
  - 必须 `SetupHelper.RegisterAssembly` 注册 Core/Vhdx/Ntfs。
  - 256 MiB 起（NTFS 元数据），实测物理占用约 132 MB —— 不要写"实际占用很小"。
- `ChertIntegration`：GUI 优先；仅当 HKCR/HKCU 检测到 `URL Protocol` 时才走 `chert://launch?path=...&type=minecraft`；`BASALT_CHERT_GUI` 环境变量可覆盖 GUI 路径。
- `CliMount`：`--daemon` 常驻；loopback TCP（`STOP <token>`）+ stdin "stop"；状态 `%TEMP%\basalt_mount_state.json`；`basalt.exe stop` 客户端。无 `--daemon` 时仅做挂载预检后立即卸载退出。

## 7z 中文乱码修复
`ContainerDiskService.LoadEntries` 加 `-sccUTF-8`，并改为读 `StandardOutput.BaseStream` 原始字节 → 严格 UTF-8 → 失败回退 GB18030。`App.OnStartup` 先 `Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)`。stderr 用 `ReadToEndAsync()` 并发读，避免 stdout 管道死锁。

## 踩坑
1. `IVirtualDisk.cs` 无 `using System.IO;`，`Stream` 解析失败（WPF 临时工程下 ImplicitUsings 不给 System.IO）→ 显式加。
2. `DecodeText` 的 `out encName` 在 try/catch 分支未赋值 → CS0177，方法开头给默认值。
3. `--previewui` 自测逐个 `Close()` 窗口时，默认 `ShutdownMode=OnLastWindowClose` 导致 Application 提前关闭，后续 `InitializeComponent` 抛「应用程序对象正在关闭」→ 测试里设 `ShutdownMode=OnExplicitShutdown`。
4. `BiosPartitionTable.CreateAligned` 返回值未用会 CS0219 → 用 `_ =`。
